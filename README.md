
# Personal Portfolio Landing Page

## Project Overview
A responsive personal developer portfolio website built using HTML5 and CSS3. It showcases my profile, technical skills, projects, and social media links in a professional layout.

## Project Purpose
To create an online professional identity where recruiters, developers, and visitors can explore my skills, projects, and contact information.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Features
- Responsive navigation bar
- Personal introduction section
- About Me section
- Technical Skills showcase
- Projects showcase
- GitHub and LinkedIn links
- Contact section
- Mobile-friendly design

## Project Structure

PersonalPortfolio/
│
├── index.html
├── style.css
└── README.md

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the portfolio website.

## Customization
- Update personal information.
- Add your profile photograph.
- Add your GitHub and LinkedIn profile URLs.
- Update project details and contact information.

## Learning Outcomes
- Understanding semantic HTML5 elements.
- Applying CSS styling and layouts.
- Using Flexbox and Grid.
- Creating responsive web pages.
- Building a personal portfolio website.
